# Meghana Lalkota — Portfolio

Personal portfolio site for Meghana Lalkota, Financial Analyst.

**Live site:** https://meghanalalkota07.github.io/meghana-portfolio/

## Pages

- **Home** (`index.html`) — intro, bio, and photo
- **Projects** (`projects.html`) — [Finance Lab](https://finance-lab.streamlit.app/), an interactive financial research platform ([source](https://github.com/meghanalalkota07/finance-lab))
- **Thoughts** (`thoughts.html`) — short notes on markets, automation, and quant finance

## Built with

Plain HTML and CSS — no build step, no framework. Fonts are Newsreader and Manrope
via Google Fonts; colors, spacing, and type scale live in `tokens.css` and are
shared across all three pages through `site.css`. Hosted on GitHub Pages.

## Running locally

Just open `index.html` in a browser — no install or server needed.
